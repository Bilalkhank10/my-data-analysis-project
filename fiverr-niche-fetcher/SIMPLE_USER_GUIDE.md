# GigCraft — Simple User Guide

## For non-technical users

### 1. Start the app

Double-click:

```text
START_HERE.bat
```

Keep the black terminal window open. Your browser will open automatically.

### 2. Check AI status

Top-right should say:

```text
AI connected
```

If it says `AI setup needed`, add a new OpenRouter key to the local `.env` file and restart `START_HERE.bat`.

### 3. Enter your service

Example:

```text
Looker Studio dashboards for ecommerce brands
```

You may optionally enter your ideal customer.

### 4. Choose research quality

- **Quick:** 10 competitors, fastest
- **Recommended:** 25 competitors plus buyer-intent analysis
- **Best quality:** 50 competitors plus deeper refinement

Use **Recommended** for most gigs.

### 5. Click the main button

```text
Create My Fiverr Gig
```

The backend automatically:

1. Researches competitors
2. Analyzes prices, packages, keywords and reviews
3. Understands buyer needs
4. Creates the title, tags and description
5. Creates Basic, Standard and Premium packages
6. Creates FAQs, requirements and exclusions
7. Creates thumbnail text and a video script
8. Checks the draft for common compliance risks

You do not need to open technical dashboards or manually run separate phases.

### 6. Wait for completion

The screen shows four simple steps:

```text
Research → Buyer needs → Build gig → Ready
```

Do not close the terminal. You may leave the browser tab open.

### 7. Copy your Fiverr gig

When complete, copy:

- Gig title
- Five tags
- Description
- Packages
- FAQs
- Buyer requirements
- Scope exclusions
- CTA
- Thumbnail text
- Video script

Each section has a **Copy** button. You may also use **Copy everything** or **Download draft**.

### 8. Review before publishing

Always verify:

- Prices match what you can deliver
- Claims are true
- Delivery times are realistic
- No personal contact/payment details are included
- Fiverr’s latest policies are followed

The app helps improve research and presentation; it cannot guarantee ranking or orders.

### 9. Create another gig

Click:

```text
Create another gig
```

### 10. Stop the app

In the terminal press:

```text
Ctrl+C
```

### Advanced tools

Technical users can open:

```text
http://127.0.0.1:8000/advanced
```

The Advanced dashboard contains raw crawl data, rankings, pricing, AI audits, token costs and diagnostics. Normal users do not need it.
